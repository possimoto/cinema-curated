v1.0은 549개 코멘트 원문을 보존하면서 source-grounded 추천, OpenAI 설명 생성, 벡터 검색, TMDB 메타데이터, 관리자 큐레이션을 하나의 Next.js 서비스 구조로 통합했습니다.
